# CrossHealth-Risk

## Context-Adaptive and Uncertainty-Aware Health Misinformation Detection

This project focuses on detecting health misinformation using textual and contextual information across heterogeneous datasets.

## Datasets

- FakeHealth - Primary training and core evaluation dataset
- CoAID - COVID-19 domain-shift/generalization dataset
- PUBHEALTH - Independent text-only generalization dataset

## Research Pipeline

Dataset
→ Preprocessing
→ Visualization
→ Feature Engineering
→ Baseline
→ Class Imbalance Experiments
→ Text + Context Fusion
→ Adaptive Gated Fusion
→ Missing-Context Evaluation
→ Cross-Dataset Evaluation
→ Uncertainty-Aware Risk Scoring
